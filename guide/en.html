Short version

  1. On your everyday computer, download the live Linux called Tails (an operating system that runs from a USB stick without installing anything) from its official site and verify it.
  2. Download this app's zip file and check its SHA-256 value (the file's fingerprint).
  3. Write Tails onto USB stick 1; copy this app's folder onto USB stick 2.
  4. Unplug the network cable, turn off Wi-Fi and Bluetooth, disconnect the printer from the network and connect it with a USB cable.
  5. Start the computer from the Tails USB stick; turn on Offline Mode on the welcome screen.
  6. Copy the app folder into the Home folder and open index.html with Tor Browser.
  7. Create the wallet, then print the PDF or write the words by hand.
  8. Shut Tails down: everything in memory is erased. Store the papers safely.

1. Why not use your current computer?

The computer you use every day has been online for years; e-mail attachments were opened, programs installed, browser add-ons added. It may contain malware (viruses, spyware) you never noticed. Such programs can:

  • Keylogger (a program that records every key you press): steal the password you type.
  • Screen capture: take a picture of the recovery words on your screen.
  • Clipboard hijacker (a program that changes text you copy): swap the address you copied for the attacker's address.
  • Cloud sync (OneDrive, Google Drive, iCloud): upload your PDF to the internet without you noticing.
  • Swap and temporary files (swap — disk space where the operating system parks memory): secrets can leave traces on disk that can be recovered even after you delete them.
Analogy: it is like writing your safe's combination in the middle of a crowded market without knowing who is watching. A clean live Linux is an empty, windowless room with the door locked.

2. What is a live Linux and how does it run in memory?

A live Linux is an operating system (the basic software that runs a computer, like Windows) that starts from a USB stick and runs without installing anything on the computer's disk.

  • When it starts, it loads itself into the computer's RAM (working memory — temporary storage that empties when the power goes off).
  • It does not touch the hard disk (the computer's permanent storage: HDD/SSD); your Windows and files stay exactly as they are.
  • The keys you create, the PDF and everything you type live only in RAM.
  • When you shut it down, RAM empties. Tails goes one step further: it overwrites memory with random data at shutdown, making the old content much harder to read back.
Analogy: like writing on a blackboard with chalk instead of in a notebook. When you are done, the board is wiped and nothing remains; nothing was ever written into your notebook (your disk).

3. Which Linux? (Tails recommended)

Linux comes in many distributions (versions of Linux prepared by different teams). For this job we recommend Tails:

  • It is designed to be amnesic: it leaves no trace after shutdown.
  • Its welcome screen has a one-click Offline Mode.
  • Its official site has a built-in tool to check that your download is genuine.
  • It has been used and audited for years by journalists and security experts.
  • It supports printers (Settings ▸ Printers).

Size and version: as of October 2026 the current version is Tails 7.15.1, a USB image of about 1.8 GB. Always download the latest version shown on the site.

Why not a lighter Linux? Very light distributions of a few hundred MB exist, but most lack the combination of offline mode, memory wiping at shutdown, easy verification and wide printer support. Tails is the smallest and easiest option that covers everything this job needs.

Fallback: if Tails does not recognise your printer at all, Linux Mint 22.3 Xfce (about 2.8 GB, linuxmint.com) includes more printer drivers (software that runs a printer). It is not designed to be amnesic: use it only in live mode without installing, and follow the offline rules below exactly. Even safer: skip the printer and write the words by hand.

4. What you need

  • Your everyday computer — only for downloading and preparing the USB sticks.
  • USB stick 1 — at least 8 GB; Tails will be written to it and everything on it erased.
  • USB stick 2 — any size; this app's folder goes on it.
  • The computer to create the wallet on — preferably a laptop; on desktops a hidden hardware keylogger (a small device that records key presses) can sit between keyboard and computer.
  • A USB-cable printer (optional) — or paper and a good pen.

5. Downloading and recognising a safe site

Go to the right site

  • Type the address yourself: https://tails.net. Do not click search-engine ads; scammers push fake sites to the top with ads.
  • The address bar must show a padlock and https:// (the connection is encrypted). A padlock alone does not prove the site is honest; the domain name must be exactly right.
  • Watch out for look-alike addresses. Scammers swap a single letter (capital I for small l), add words (tails-free-download…), use another ending (.com, .org) or put the real name first and change the end (tails.net.another-site…). The only correct address is exactly tails.net.

Verify the file you downloaded

The Tails download page has a "Select your download to verify…" button. Select the file you downloaded; do not continue until you see "Verification successful!".

Analogy: verification is like checking that the seal on a parcel matches its contents. If even one letter of the file changed, the result is "failed".

Verify this app's zip

Download the zip only from the project's GitHub Releases page: https://github.com/snipeTR/OfflineKey-Vault/releases. The SHA256SUMS file next to it holds the zip's SHA-256 value (the file's unique fingerprint). The value you compute must match it exactly:

  • Windows: open Command Prompt and type certutil -hashfile OfflineKey-Vault-X.Y.Z.zip SHA256
  • macOS: in Terminal, shasum -a 256 OfflineKey-Vault-X.Y.Z.zip
  • Linux: sha256sum -c SHA256SUMS (must print "OK").

6. Preparing the USB stick

  1. Open the install page (Install) on the Tails site and choose your operating system. Use the writing tool the site recommends (a program that copies an operating system onto a USB stick; usually balenaEtcher on Windows and macOS).
  2. In the tool, choose your verified Tails file with Flash from file, choose USB stick 1 with Select target, and press Flash.
  3. Careful: everything on the selected stick is erased. Make sure you picked the right one.
  4. Copy this app's zip onto USB stick 2 and extract it (turn it into a folder).

7. Cutting the network — how and why

Why?

Your secret key is a short text of 64 characters; a single small network packet (a piece of data sent over the internet) is enough to leak it. If the computer is not connected at all, the information cannot get out even in the worst case. This is called an air gap (no physical link between the device and the internet). This app never sends anything anyway, but ultra security means making a leak impossible instead of trusting that it will not happen.

How?

  • Unplug the Ethernet (network) cable if there is one.
  • On laptops press the airplane mode key or turn off the Wi-Fi switch; turn off Bluetooth too.
  • Turn on Offline Mode on the Tails welcome screen (section 8). This disables networking inside Tails as well.
  • Turn off the printer's Wi-Fi or unplug its network cable; connect it only with a USB cable.
  • Leave your phone in another room: its camera can see the screen.

8. Starting Tails

  1. Plug in USB stick 1 and restart the computer.
  2. While the screen turns on, press the boot menu key (the menu where you choose which disk the computer starts from) repeatedly. Depending on the maker it is usually F12, Esc, F9, F10 or F11.
  3. Choose the USB stick from the list. Tails works with Secure Boot (a setting that only lets signed systems start) on most computers.
  4. On the Welcome Screen, choose your language and keyboard layout.
  5. Press the "+" (Additional Settings) button:
    • Turn on Offline Mode.
    • Administration Password (permission to change system settings): may be asked for when adding a printer; set a simple password for this session.
  6. Press Start Tails.

9. Running the app

  1. Plug in USB stick 2. With the Files app, copy the app folder into Home (the user's personal folder). Why? For safety, Tor Browser in Tails can only read files in the Home folder.
  2. Open Tor Browser. A warning that Tor is not connected is normal; we are not going online.
  3. Press Ctrl+O and choose index.html in the folder.
  4. Check with the shield icon next to the address bar that the security level is Standard. Higher levels turn off JavaScript (the page's calculating code) and the app will not work.
  5. At the top of the app you must see "You are offline" and "All critical tests passed". If not, stop.
  6. Create the wallet step by step. For the smoothest result in Tor Browser choose the English word list and no background image: to prevent tracking, Tor Browser restricts pages from reading image data (canvas — the page's drawing area); if it asks for permission you may allow it.

10. Using the printer offline

Why it matters

  • Network and Wi-Fi printers receive the document over the network; another device on that network may see it.
  • Cloud printing (printing services over the internet) sends your document to company servers.
  • Some printers, especially large office machines, can keep printed jobs in their own memory or disk.
  • Never print at a copy shop or at work.

How

  1. Connect a simple home printer with a USB cable, with its Wi-Fi off.
  2. In Tails open Apps ▸ System Tools ▸ Settings ▸ Printers. Most current printers are recognised automatically as driverless (working through a standard language without extra software).
  3. To be sure, look up your printer model beforehand, on your everyday computer, in the OpenPrinting database (a site listing which printers work on Linux).
  4. In the app press Create and download PDF, open the downloaded PDF in Tor Browser and print with Ctrl+P. Make sure the scale is 100% / actual size, otherwise the card dimensions change.
  5. After printing, switch the printer off and unplug it for a few minutes; its temporary memory empties.
Inkjet or laser? Laser (toner) prints resist water and time better. Keep inkjet prints away from moisture.

11. Without a printer: writing by hand

The safest way is not to use a printer at all: no printer, no printer memory.

  • Write the words with their numbers, in large, clear letters.
  • Compare what you wrote with the screen letter by letter; a single wrong letter makes the wallet unrecoverable.
  • You may write your address (the public data for receiving money) on a separate paper; sharing the address is safe.
  • For long-term storage consider stamping the words into a metal plate (a fire- and water-resistant backup).

12. Finishing and storing

  1. Cut the cards along the guide lines.
  2. Shut Tails down (top-right menu, Power Off). Memory is wiped; nothing, including the PDF, remains.
  3. Remove your USB sticks. The app stick holds no secrets (unless you saved some there).
  4. Keep the papers where only you know, safe from water, fire and sunlight. If you used Shamir shares, keep each share in a different place.
  5. If you used a passphrase (an extra secret password), store it separately from the cards.
  6. Before depositing a large amount, send a small amount and check that the address works. Never type the recovery words into an internet-connected device to test them; if you must test, do it in an offline Tails session again.

13. Common mistakes

  • Taking a photo of the words or noting them on a phone.
  • E-mailing the PDF to yourself or saving it to the cloud.
  • Printing on a Wi-Fi printer or at a copy shop.
  • Using Tails without verifying it, or downloading it from a fake site found through an ad.
  • Keeping the words on a single paper in a single place (fire, water, loss).
  • Writing the passphrase on the card.

14. Can I use a phone or tablet?

You can, but you will not reach the "ultra security" level of this guide. A phone is a computer in your pocket that is always online and runs dozens of apps:

  • You cannot start a phone with a clean, amnesic (leaves no trace after shutdown) system; everything happens in the system you use every day.
  • Keyboard apps (especially installed ones) can learn and store the words you type.
  • Screenshots and photos are often backed up to the cloud automatically (Google Photos, iCloud).
  • Something saved while in airplane mode can be sent once the internet is back.

If you still use a phone (for small amounts)

  1. Download the single-file edition (OfflineKey-Vault-X.Y.Z.html) from the releases page. The multi-file edition in the zip cannot open on phones; the single-file edition carries everything in one page.
  2. Turn on airplane mode; keep Wi-Fi and Bluetooth off.
  3. Android: tap the file in the Files app and open it with Chrome or Firefox. Check that the top of the page says "You are offline" and "All critical tests passed".
  4. Write the words on paper by hand; do not take screenshots or download the PDF.
  5. When done, press "Clear and start over", close the browser tab, then leave airplane mode.
iPhone / iPad: iOS does not let a local HTML file run its code, so the app cannot currently run offline on these devices. Use Tails on a computer instead.

Note: the single-file edition is tested in desktop browsers and at phone screen size; it has not yet been tried on real Android devices.
