# v0.6.0 — built and published by GitHub Actions
### Downloads
- **Computers:** `OfflineKey-Vault-0.6.0.zip` — extract, disconnect from the internet, double-click `index.html`.
- **Phones (Android):** `OfflineKey-Vault-0.6.0.html` — single-file edition; open it in airplane mode with Chrome or Firefox.
- Check both with `sha256sum -c SHA256SUMS`.

### New
- **Release files are now built on GitHub's servers**, not on a personal computer. Pushing a version tag runs `.github/workflows/release.yml`: Node.js tests, build of the zip and the single-file edition, browser tests (Chrome, Edge, Firefox) on the unpacked zip, then publication.
- **Build provenance:** each file comes with a GitHub-signed record of the exact commit and workflow that produced it. Verify on an online computer with the GitHub CLI:
  `gh attestation verify OfflineKey-Vault-0.6.0.html --repo snipeTR/OfflineKey-Vault`
- The release tool refuses to run with uncommitted changes.

No changes to the app itself since v0.5.1.

⚠️ Pre-release: test-restore every wallet with a small amount before using real funds. Not yet tried on a real Android device; Safari has not been tested.
